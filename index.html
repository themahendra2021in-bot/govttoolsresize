आधार / PAN PDF

🔐 पासवर्ड वाले आधार / PAN PDF खोलें और Crop करें

पासवर्ड-सुरक्षित PDF चुनें → पासवर्ड डालें → पेज खोलें → Crop करके JPG/PNG डाउनलोड करें।

1. PDF और पासवर्ड

अभी कोई PDF नहीं चुनी गई।

पासवर्ड आपके ब्राउज़र में ही उपयोग किया जाता है। इसमें PDF को किसी server पर भेजने की आवश्यकता नहीं है।

2. पेज चुनें

PDF खुलने के बाद पेज की जानकारी यहाँ दिखेगी।

3. Crop और Download

PDF खोलकर पेज render करें।
महत्वपूर्ण: यह सुविधा पासवर्ड-सुरक्षित PDF को सही पासवर्ड से खोलने के लिए है। पासवर्ड को bypass/crack करने की सुविधा नहीं है। कुछ PDF में अलग तरह की security हो सकती है। PDF.js library इस सुविधा के लिए इंटरनेट से लोड होती है; बाकी image processing browser में local रहती है।

🚘 Driving Licence — सरकारी स्रोत से प्राप्त करें → Crop करें
